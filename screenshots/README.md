## Regenerate

```powershell
# 1. Start the portal
node server.js

# 2. From another shell, install dependencies (including Playwright) and run the capture
npm install
npx playwright install chromium
$env:BASE_URL = 'http://localhost:3000'   # omit if the portal uses this default
node scripts/capture-screenshots.js
```

The script visits each route with `?clawpilotTheme=light` and `?clawpilotTheme=dark`,
waits for any visible "Loading…" banner to clear (up to 45 s, because the Power
Platform page fans out about 20 upstream calls on a cold cache), and overwrites the
PNGs in this folder.

| Environment variable | Purpose |
|---|---|
| `BASE_URL` | Portal address. Defaults to `http://localhost:3000`. |
| `ONLY` | Comma-separated slugs to re-capture, for example `ONLY=home,weekly-briefing`. |
| `CHROMIUM_PATH` | Path to an existing Chromium or headless shell, if `npx playwright install` isn't an option. |

The Message Center, Service Health, and weekly briefing pages need Microsoft Graph
credentials to show tenant data. Capture those pages with a configured server and
check the images for anything you don't want to publish before committing them.
